日期：2026-09-26。状态：**测量完成，资源和失败处理契约冻结；M2 标题任务尚未接入产品。**

脚本：[benchmark-qa-m0-titles.mjs](../scripts/benchmark-qa-m0-titles.mjs)；[固定样本](fixtures/qa-workspace-m0-title-cases.json)；[16 次实际结果](fixtures/qa-workspace-m0-title-baseline-2026-09-26.json)。样本仅含合成问答与文件显示名，没有真实用户资料。调用复用当前 `createQaChatCompletion`，模型 `deepseek-flash`，`reasoningEffort=quick`、temperature 0.1、max_tokens 64；不经过 Agent 工具循环。

## 1. 实际结果

8 个案例各调用 2 次，串行执行，16 次请求均返回完整 `stop` 和已知 usage，没有重试。p50 **618.087 ms**、p95 **1,030.039 ms**；这只是本轮短输入的供应商样本，不是线上 SLA。

| 输入 / 输出合计 | 2,214 / 93 tokens |
| 明确缓存命中 | 0 tokens |
| 格式、语言、关键词与注入标记检查 | 14 通过、2 需处理 |
| 调用前按峰时单价预留 | ¥0.039524 |
| 按返回 usage 与峰时单价估算 | ¥0.005172 |
| 同样 usage 按非峰时单价估算 | ¥0.002586 |

单价来自 2026-09-26 核对的 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：每百万 token 峰时缓存命中输入 0.04 元、未命中 2 元、输出 8 元；非峰时分别为 0.02 / 1 / 4 元。为预算保守使用峰时价。usage 费用是估算，**不是供应商账单**；以后重测先核对价格，不能把日期快照当成永久价格。

人工复核发现 `en-methods` 两次英文问题均返回中文“两篇论文实验设置对比”。最初词面检查未覆盖语言，现已补语言断言并对**已保存输出离线重评分**，没有追加付费请求。原始输出、耗时、usage 和这次修订说明均保留。

此外，“未证笔记问题”表达生硬，注入案例的标题偏泛。这意味着 14/16 也只是有限规则检查，不能称为 87.5% 的产品标题质量。英文失败样本成为 M2 的必测反例。

## 2. 冻结的调用预算与行为

| 边界 | 冻结值 / 行为 |
| --- | --- |
| 输入 | 只投影本轮已保存问题的前 360 UTF-8 bytes、成功答案前 480 bytes、最多 2 个附件显示名各 96 bytes；按 Unicode code point 截取，不破坏 UTF-8 |
| 预留 | `JSON(messages)` UTF-8 字节数 + 256，最多 2,048 个**保守预留单位**；不是精确 tokenizer，实测 token 以供应商 usage 为准 |
| 输出 | max_tokens=64；中文最多 24 个 code point / 英文最多 8 词；单行、无标题前缀，语言与问题一致 |
| 排队 | 每用户最多 1 个待处理任务；进程最多 1 个活动标题调用、最多 16 个待处理任务；只在前台问答准入有空余时启动 |
| 超时 / 重试 | 15 秒；首版每个成功首轮最多 1 次辅助调用，自动重试为 0；用户显式“重新生成标题”另建 nonce 和预算 |
| 提交 | 必须仍符合线程、消息、标题、生命周期 revision 的 CAS；手动名与旧会话标题默认保护 |
| 不可用结果 | 语言/格式/完整终态不符、超时或请求完成状态未知时保留临时标题，不另开调用“修复”；未来主题质量校验不依赖本次人工关键词 |
| 费用未知 | 缺 prompt/completion usage 不能记为 0 元或标为完整成功；记录 unknown，单列已知费用小计，停止测量批次，不盲目重付费 |

这些投影只用于辅助标题，**不改写用户已保存的问题、回答或输入附件**。本轮最大保守预留为 1,350、实际输入最多 211 tokens；没有测过 2,048 个真实 token 的长输入质量。摘要任务在 M5 单独测量，不复用标题费用作估计。

前台优先、持久队列、CAS、限额及临时标题回退是 M2 的实施契约，当前新增的是测量脚本和离线故障检查。没有创建后台 worker、开放 API 或改变当前首问截断标题。

## 3. 复现与故障检查

普通 CI 只运行 mock 测试，不需要密钥或产生费用：

```bash
node scripts/benchmark-qa-m0-titles.mjs
node --test tests/qa/m0TitleProbe.test.mjs
```

第一条默认仅显示 dry-run。真实测量必须显式 `--run`，最多 16 次、峰时预留上限 ¥0.25、无重试；只读取指定环境文件的 `DEEPSEEK_API_KEY` 并调用官方地址，不连接数据库。输出不保存凭据、供应商错误正文或推理过程。结果包含每次原始标题、检查项、usage、提示与样本哈希；遇到网络/usage 异常写入已完成记录后停止。

```bash
node scripts/benchmark-qa-m0-titles.mjs --run \
  --env-file=/path/to/provider.env --output=/tmp/qa-m0-title-rerun.json
```

语言或终态等检查不通过、usage 未知、请求未完成计划数量都会返回非零；本轮保留的 14/16 应被判定为需要处理的质量基线，不能更改检查器把它洗成全通过。
