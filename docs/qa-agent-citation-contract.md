# QA Agent 第二阶段：章节与原文行引用契约

日期：2026-09-24。契约草案：`citation-locator-v1`。
状态：**契约已实现 / 自动化验证已执行 / 数据库迁移和本地切换待完成 / 人工验收待进行**。

本文补充 [第二阶段方案](qa-agent-stage-2-plan.md) 的第 5、7、11 节。
本文是实现约束，实际落地与验证边界见 [P2 实施记录](qa-agent-stage-2-implementation.md)。整行高亮已实现，逐字高亮继续不在范围内。

## 1. 交付范围与职责

目标场景：用户问“XXX 在文中是怎么实现的”，模型解释实现步骤，并在关键论断后给出可点击引用。
点击引用后，阅读器定位到对应章节，或高亮支撑该论断的关键句所在原文行。

**模型负责“我看了哪些资料，其中哪些原文最重要”；harness 负责把这些选择映射回真实文档。**
模型不计算章节边界、页码、行号、字符偏移或矩形坐标，也不通过猜测这些值来修复定位失败。

| 责任 | 模型 | harness / 软件实现 |
| --- | --- | --- |
| 阅读和理解 | 规划查阅，选择工具提供的资料标识，理解内容 | 鉴权，提供有来源映射的文字，记录实际阅读覆盖 |
| 选择重要内容 | 返回已读来源标识及原文摘录，或选择整个已读资料范围 | 验证选择属于已读内容，定位唯一原文，冻结引用 |
| 章节与位置 | 无须输出章节位置或页行坐标 | 从来源映射取得所属章节、页行范围和行框 |
| 最终回答 | 使用 harness 返回的引用编号解释实现方式 | 核验编号，保存来源快照，执行点击定位和高亮 |

本期交付两项：章节定位；关键句所在原文行高亮。
**暂不实现字词级高亮**：关键句涉及的行可以连同同一行其他文字一起高亮。
字符偏移可以作为软件内部的来源映射使用，不意味着本期要实现逐字绘制。

新路径不依赖预切 chunk、embedding、向量召回或 rerank；页行视图仍依赖已授权解析产物。
模型看到的资料标识是阅读工具动态返回内容的来源句柄，不是预先向量化的检索块。
阅读覆盖、重要原文范围与显示高亮范围分别记录，不能因高亮整行而宣称模型读过该行所有文字。

## 2. harness 维护的来源映射

### 2.1 冻结视图与精确覆盖

- `pageNumber` 为从 1 开始的 PDF 物理页号；印刷页码仅作补充显示。
- `lineNumber` 为冻结视图中原始页行数组的下标加 1，空行也占位。
  不随搜索排序、文本归一化、前端换行或缩放改变；它不是 PDF.js 的 span 序号。
- `documentVersion` 覆盖文档内容和解析产物修订，`viewVersion` 标识阅读视图规则。
  重新 OCR 或规则变化后，不得把旧行号或坐标套用到新视图。
- 服务端为每份实际返回的资料维护 `readCoverage`：返回文字到原始页、行及行内字符区间的映射。
  字符区间使用原始 JavaScript 字符串的 UTF-16 下标，起点包含、终点不包含；全部由程序生成和校验。
- 行矩形补充 `lineNumber`，便于按映射筛选。缺少矩形时保留原文身份，不用邻行矩形代替。
- MMD 与原文行无法可靠对齐的内容标为不可定位的补充资料，不能生成假页码或行引用。

### 2.2 工具向模型提供的资料

`read_document` 和 `search_document_text` 的每项可引用资料至少提供：

| 模型可见字段 | 用途 |
| --- | --- |
| `evidenceId` | 当前运行来源编号，如 C2；模型选择自己实际读过的资料 |
| `text` | 原文内容；省略号、截断说明与原文分开，模型可直接摘取重要句段 |
| `scopeLabel / coverageStatus` | 可用的章节名称、已读范围说明、完整/部分覆盖状态及续读提示；均由软件生成 |

服务端同时保留 `evidenceKey`、文档版本、`readCoverage`、章节映射和行坐标。
现有页码等元数据可以用于说明来源，但模型无须抄写或推算这些值；引用接口不接受它们作为定位依据。
阅读工具可继续支持服务端目录产生的 sectionId、页范围和全文模式；这属于选择阅读入口，
不要求模型自行推导某章节实际位于哪些页或某句位于哪一行。

目录条目、命中总数及“已扫描全文”不是正文阅读证据。
搜索预览只有实际返回文字进入 readCoverage，隐藏上下文和未返回的后续页均不算已读。
预览中的完整关键句可以引用；句子截断时模型须补读，不能补写缺失文字再把它当原文。
即使预览只有一行中的部分内容，也可映射到该行框；来源支持范围仍仅限已经返回的文字。

长章节通过续读累积覆盖，只看标题或前半章不能称为读完整章。
跨轮历史须重新检查授权和版本，并将相应原文实际提供给本轮模型，才能恢复本轮阅读覆盖；
仅有上一轮答案、编号或摘要不能恢复整段证据。原文不可用时不得依靠旧编号继续定位新事实。

## 3. finish_reading：只声明来源与重要内容

复用拟议 `finish_reading` 控制动作，不增加独立的引用定位模型调用。
本补充用 `citationSelections` 取代早期 P2 草案的 `evidenceIds` 输入，避免两组可写字段表达不同证据集合。
这是 P2 原生工具路径的契约，不改变旧执行器的 finish_retrieval。

```ts
type CitationSelection =
  | {
      kind: "quote";
      sourceEvidenceIds: string[];
      quote: string;
      contextBefore?: string;
      contextAfter?: string;
    }
  | {
      kind: "source";
      sourceEvidenceIds: string[];
    };

type FinishReadingArgs = {
  mode: "grounded" | "direct" | "insufficient";
  citationSelections: CitationSelection[];
  answerOutline: string;
};
```

- `quote` 表示“这些已读资料中的这段原文最重要”。必须摘取原文，不能使用翻译、摘要或省略拼接。
  `contextBefore / contextAfter` 是可选的紧邻原文，仅用于消歧，不属于最终引用原文。
- `source` 表示“这些已读资料的整体范围是依据”。harness 根据真实覆盖判断它是否对应完整章节，
  不要求模型输出章节 ID、章节名称或章节位置作为引用选择。
- sourceEvidenceIds 必须属于当前模型已收到的资料；模型不能填写用户、文档 ID、页码、行号、offset 或坐标。
- `grounded` 至少一个选择；`direct` 必须为空且不输出论文事实引用；`insufficient` 可保留已有依据，说明未找到部分。

以上为逻辑类型；正式实现由单一 JSON Schema 表达，禁止未知字段、隐式类型转换及补业务参数。
首版最多 12 个选择，每项 1～16 个不重复来源编号；quote 为 1～2,000 字符，非空 context 各最多 500 字符，
answerOutline 最多 2,000 字符。字符长度按 Schema 的字符串长度口径校验，不与内部 UTF-16 偏移混用。
`source` 不接受 quote/context 字段。调整上限须同步 Schema、契约版本和评测。
所有选择仍受 P2 全局模型、工具、上下文和修正预算限制，不形成额外额度。

## 4. harness 的确定性映射与校验

### 4.1 重要原文定位

1. 验证结构、模式和上限，以及本运行授权、文档和解析版本。
2. 解析来源编号，取得模型实际收到的文字及其 readCoverage；来源必须属于同一授权文档版本。
3. `quote` 仅在所列已读来源中匹配，使用带反向映射的 Unicode NFC 和空白归一化副本。
   不做语义近似、OCR 纠错替换、自动补词或全篇重新猜测；匹配结果必须能还原到原始字符区间。
   归一化后为空的摘录或上下文属于非法参数；组合字符等长度变化必须通过反向映射处理，不能直接套用归一化偏移。
4. 如有 contextBefore/contextAfter，要求它们也是已读原文，且分别紧邻 quote 的前后，进一步缩小候选。
   未命中即失败；仍有多处匹配即返回歧义，不能默认取第一个或让模型猜页码。
5. 唯一匹配后，由 readCoverage 导出选中原文的 sourceSpans，再取得章节路径、行范围、已有行框及默认落点。
   原始字符范围是引用依据；高亮范围只向外扩展到覆盖这些字符的原文行。

同一原文通过重复读取得到多份来源时，先按真实位置合并候选，不能将同一个位置误判成多处匹配。
跨页或跨续读的 quote 可以使用多个来源；只有来源在原文中连续、所选文字全被返回且无未读缺口时才允许拼接。
不同位置的原文不得因为去掉中间段落而变成一个连续 quote，应分别选择并生成多个引用。
每个声明的来源都必须贡献匹配原文或消歧上下文，不能混入无关来源扩大搜索空间。

这些来源映射不是模型生成内容；不接受“模型说在第 7 页”作为补充定位证据。
映射失败返回可修正工具错误，模型可以补读、缩小来源集合或补充原文上下文。
错误返回至多三个候选的已读上下文及来源编号，不暴露未读正文，不要求模型填写坐标。

### 4.2 整体来源与章节定位

`source` 对所列来源的真实覆盖求并集，去重后必须构成连续且有正文的已读范围；有未读缺口时拒绝。
如范围恰好完整覆盖本版本目录中的一个章节，harness 将其解析为 `kind=section`，采用软件记录的章节起点。
嵌套章节有完全相同边界时取最深层的可信目录项，规则推导目录保留 inferred 标记。
其他合法情况解析为 `kind=range`，显示实际已读范围及可确定的章节归属，不宣称引用了整个章节。
整体资料覆盖多个章节时不能随意取其中一个章节名代表全部范围。

quote 解析为 `kind=lines`，所属章节也由软件推导，不要求模型再选择整章才能显示章节标签。
章节边界、sourceSpans、行号和矩形全部由 harness 确定。

### 4.3 错误与原子性

| 情况 | 返回或处理 |
| --- | --- |
| 模式、未知字段、类型或长度不合法 | INVALID_TOOL_ARGUMENTS；模型提供位置字段也属于非法参数 |
| 来源编号不属于本次可用资料 | UNKNOWN_EVIDENCE |
| 摘录或消歧上下文未在已读来源中匹配 | QUOTE_NOT_FOUND；可补读或重新摘取，不能悄悄改为整页引用 |
| 摘录仍对应多处真实位置 | AMBIGUOUS_QUOTE；返回有限的已读上下文帮助选择 |
| 来源不连续、有未读缺口或混入无关来源 | CITATION_OUTSIDE_READ_SCOPE |
| 原文无法反向映射到可信来源 | SOURCE_MAPPING_UNAVAILABLE；不生成看似精准的引用 |
| 原文可映射，但坐标部分/全部缺失 | 选择可成功；返回实际定位精度和缺失坐标说明 |
| 权限撤回、删除或版本变化 | 终止本轮；不能改参数继续引用旧版本 |

一次 finish_reading 的所有选择一起校验；任一失败时，不分配新 C 编号、不冻结部分结果，也不进入最终答案阶段。
修正沿用 P2 全局最多两轮及总调用预算。没有歧义但选错了语义证据，不会被位置校验自动发现；
校验结果只证明来源和位置一致，不能标记为“原文已经证明模型结论”。

## 5. 引用身份、回传与最终答案

唯一映射后，以授权文档、documentVersion、viewVersion 和规范化 sourceSpans 形成稳定 evidenceKey。
sourceSpans 为软件内部的原文字符区间集合，每项包含 pageNumber、lineNumber、startOffset、endOffset。
因此同一行中的两个不同摘录有不同身份，即使本期高亮矩形相同，也不会混为同一证据。
相同范围复用身份及 C 编号；缩小范围产生新身份和编号，并保留父 sourceEvidenceKeys。
不能将 C2 从“整段阅读结果”改写成“其中关键句”；重排、重复读取和缓存命中不能重编号。
同一次选择映射到相同来源范围时按首次出现去重，保留所有实际使用的父来源关系。

成功 tool 结果包含 mode、allowedCitationIds、resolvedCitations 及校验后的 answerOutline。
每项 resolved citation 包含：

| 字段 | 由 harness 产生的内容 |
| --- | --- |
| evidenceId / evidenceKey / sourceEvidenceKeys | 当前编号、稳定身份及父来源关系 |
| documentVersion / viewVersion | 冻结来源版本 |
| kind / sourceSpans / sectionPath | lines、section 或 range；真实原文范围及章节归属 |
| quotedText / quoteTruncated | 来源原文预览，最多 700 字符；省略标记独立保存，不写进原文 |
| anchor / lineRegions | 默认落点与所选行框；至少可定位到物理页 |
| locationPrecision / missingRegionRanges | 实际定位精度与缺失坐标范围 |
| selectionOrigin | model_quote、model_source 或 budget_stop |

模型侧回传必须提供“选择 → 最终 C 编号”映射、原文确认和定位状态；sourceSpans 与矩形可只留在服务端/前端。
quote 的完整来源内容及映射进入授权证据快照，不能用 700 字符展示预览代替完整范围核验。
提纲如含旧 C 编号，模型依据返回的映射调整；最终答案只能使用 allowedCitationIds。
最终 verifier 的核对集合是本次冻结引用，不是所有曾读取的资料；不允许前端按相似文字猜编号关系。
未知、未选中的编号不得生成可点击引用；缺失必需引用或存在非法引用时明确显示引用校验失败，不能记录为 grounded 成功。
保留已生成正文与错误状态，不为修复引用再自动生成一次答案。

硬预算结束而没有成功 finish_reading 时，不再调用模型选句。
harness 只可冻结已经完整返回的来源范围，标记 selectionOrigin=budget_stop，禁止用关键词规则冒充重要句选择。
回答明确提示“查阅因预算结束，引用为已读范围”，不能计作关键句引用成功；没有合法来源时给出证据不足说明。

## 6. 示例：模型选原文，软件找位置

以下为合成示例，不对应真实论文。工具返回 C2 的原文：
“先将输入转换为特征向量。随后通过门控权重融合不同分支。融合后的表示用于最终预测。”
harness 已记录这些文字对应第 7 页第 12～14 行，属于 4.2 节，且三行均有坐标。

模型无需填写这些位置，只提交：

```json
{
  "mode": "grounded",
  "citationSelections": [
    {
      "kind": "quote",
      "sourceEvidenceIds": ["C2"],
      "quote": "随后通过门控权重融合不同分支。"
    }
  ],
  "answerOutline": "解释不同分支如何通过门控权重进行融合。"
}
```

harness 在 C2 的已读文字中唯一匹配摘录，计算出它属于第 13 行，分配子范围编号 C3，保留 C2 原意。
返回 allowedCitationIds=["C3"] 及确认原文；模型回答“XXX 使用门控权重融合不同分支。[C3]”。
点击 C3 时软件定位第 7 页第 13 行，展示“4.2 节 · 第 7 页”，只高亮这一行。
如果同一行还有其他文字，可一起高亮；模型没有承担寻找章节位置或坐标的职责。

如模型选择完整已读资料，选择项为：

```json
{
  "kind": "source",
  "sourceEvidenceIds": ["C1", "C2"]
}
```

harness 判断两个来源联合覆盖是否对应一个完整章节；只有匹配真实章节边界时才使用章节定位，
否则保持实际已读范围。不能因模型说“这一章”就把未读内容包含进来。

## 7. 阅读器定位与可见降级

| 来源与坐标条件 | locationPrecision | 必须展示的行为 |
| --- | --- | --- |
| 关键原文所涉及行坐标完整 | line | 滚动到首行，只高亮映射涉及的行；同一行其他字词可以一起高亮 |
| 只有部分所选行具备坐标 | partial-line | 仍以范围起点定位，仅高亮可用行；提示部分原文行缺少坐标 |
| 所选行全部缺少坐标 | page | 跳到起始物理页，显示原文预览及“仅支持页码定位” |
| 完整章节有起点坐标 | section | 滚动到章节起点，可短暂高亮标题或起始行，显示章节范围 |
| 章节起点无坐标 | page | 跳章节起始页，保留章节标签并说明页码定位 |
| 整体已读范围未对应完整章节 | 按可用坐标为 line / partial-line / page | 显示实际范围，不冒充完整章节或关键句选择 |

默认落点由映射确定为所选范围起点或章节起点，不再沿用旧阅读器“坐标最多的一页”的选择规则。
跨页显示完整页范围及逐页跳转入口；首次定位起始页，切换页面只高亮该页属于所选范围的行。
不把多页矩形画在同一页、不拼入相邻段落；临时高亮可沿用现有约 2.4 秒显示时间。
没有可靠目录时仅显示真实页行；跨章节引用展示真实的多个归属，不伪造单一章节名称。
文档或解析版本改变后保留历史原文预览并提示“来源版本已变化”，不将旧坐标叠到新版本。

点击响应分为浏览和高亮确认两段：当前文档 ID 与 PDF 指纹均一致时，可先按历史快照滚动浏览，
同时显示来源核验提示；这一步不绘制任何引用高亮，也不代表来源已通过核验。
每次点击仍重新远程检查授权与解析版本，通过后才画高亮；失败或版本改变则只保留浏览位置和错误提示。
确认结果不再次强制滚动；后一次点击或切换文档使前一次核验结果失效。指纹缺失时先核验再定位，指纹不符则拒绝。

harness 的摘录匹配发生在有版本、已读范围限制及反向映射的资料层。
阅读器直接使用保存的定位，不再依靠前端全局字符串匹配来决定新引用的位置。
旧引用的 PDF.js 文字匹配回退保持兼容，不能据此宣称新来源已经通过映射核验。

## 8. 保存、兼容与缓存

- 沿用 P2 拟议的 source_kind=document_text、source_version、evidence_key 和 source_locator。
  source_locator 保存契约版本、kind、sourceSpans、章节标识（如有）、viewVersion、anchor、实际精度和缺失坐标范围。
- 消息引用快照保留 C 编号、来源关系、重要原文与实际阅读覆盖、章节路径、行坐标和 selectionOrigin。
  数据库记录与快照须表达同一来源；不能仅依赖未来可能被覆盖的解析产物来重建历史。
- 新引用使用有效 evidenceKey 关联；旧引用继续读取真实 chunkId。空 chunkId 不参与相等匹配，不伪造 chunk 记录。
- 追问带入与再次保存不得丢失原文映射、lineNumber、lineRegions 或来源版本；本轮新建显示编号，历史按自己的快照解释。
- 选择和映射只读取本运行已授权视图，不触发 embedding、rerank 或额外引用定位模型调用。
  结果可按版本、来源与选中文字在本运行复用；沿用稳定工具 Schema 和追加式消息，不改写已返回的父证据。
- 先扩展兼容存储，再发布兼容读取及阅读器，最后开放新写入；正式迁移、代码和接口版本变更留在 P2 实施。

## 9. 后续实施的必过验收

以下是验收标准；自动化与浏览器合成验证结果见实施记录，不能替代真实论文的人工语义验收。

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| C01 | “XXX 怎么实现”，模型只选来源编号和重要原文 | harness 得出正确章节/行位置，父编号不变，仅高亮关键句涉及的行 |
| C02 | 选择整体已读资料 | 完整对应章节才按章节定位；部分章节显示真实已读范围，不扩大到未读内容 |
| C03 | 相同句子多次出现，或同位置被重复读取 | 不同位置返回歧义，补充已读上下文/来源后唯一定位；同位置去重，不跳到全文第一处 |
| C04 | 原文跨页且后一页行数更多 | 软件计算范围，默认落起始页，可逐页查看，高亮不越过所选原文涉及的行 |
| C05 | 模型提供位置字段、改写摘录或未读上下文 | 拒绝非法参数/映射；整体失败，不产生部分编号，不偷偷改成页级引用 |
| C06 | 搜索预览截断或来源中有未读缺口 | 只映射实际返回的原文，截断句需补读，禁止跨未读段拼接；整行渲染不扩大证据支持范围 |
| C07 | 无目录或坐标部分/全部缺失 | 章节和精度状态真实，原文可映射但无坐标时按页降级，不伪造矩形 |
| C08 | 重排、缓存命中、追问与刷新历史 | 同范围身份稳定，当前/历史 C 映射正确，原文映射与坐标不丢失 |
| C09 | 重解析、删除或权限变化 | 不继续旧版本取证，历史不能错叠新版本或泄露其他用户资料 |
| C10 | 最终答案使用未选中的父编号或编造编号 | 不建立可点击引用，明确记录引用校验失败，不自动重生成答案 |
| C11 | 未完成选择即预算耗尽 | 明示整体已读范围或证据不足，不冒充模型已选关键句 |
| C12 | 无索引、无 embedding/rerank 配置 | C01/C02 可完成，相关外部调用均为 0；新旧引用读取兼容 |

离线契约测试检查覆盖、唯一匹配、Unicode/空白反向映射、跨行跨页、编号及行框筛选；
浏览器验证滚动、跨页导航、缩放和历史恢复。真实模型人工验收另检查关键步骤是否有引用、原文是否支持解释、范围是否足够具体，
至少包含一个需要综合多个原文位置的实现问题；位置正确不能替代语义支持与覆盖验收。
逐字高亮不计入失败项；缺坐标的文档按可见降级验收，不能计作完整行高亮成功样本。
