2026-09-25。状态：用户已授权本轮 UI 修复更新到隔离测试页 5175；QA 8791 保持运行。UI 本地检查与浏览器校验通过，用户人工验收待进行。5174 / 8789 原验收入口继续保留，未部署生产。

## 实现范围

- 顶部保留阅读／研读／对话切换，以及 AI 问答、自由翻译、文献库、设置四个图标。设置齿轮直接打开设置面板，服务状态、账号和选择模式收纳其中；不再提供三点菜单。设置支持 Escape、焦点圈定及关闭后返回入口。
- 左侧会话／文档导航与右侧注释区使用同一套 30 × 30 无边框按钮，图标 16px，同一水平位置；收起后不再保留空白窄栏，展开导航嵌入当前可见的对话／文章标题栏左侧，展开注释嵌入文章标题栏右侧；对话、文章及两侧栏的标题高度统一为 48px。右侧仅显示注释。
- 会话侧栏支持服务端搜索、分页、置顶、内联重命名和软删除撤销；修改受服务端用户及 workspace scope 校验。单独删除过的回答不会因撤销会话删除而恢复。
- 每个已打开会话保留组件状态，视图／会话切换不取消后台回答；不同会话的草稿分开。刷新网页不承诺恢复未发送草稿。
- 工具事件附加 harness 生成的 `payload.activity`，包含实际文档名、页范围、章节、查询词、发现数量和未读完状态。此数据不加入模型上下文。旧历史缺少该字段时继续展示旧摘要，不推断虚构阅读位置。
- 来源默认显示 3 个，可展开／收起；保留正文引用和逐页定位，不再重复显示同一批来源快捷入口。
- 首轮等待为中性的“正在准备回答…”，发生工具事件后才展示具体查阅过程。PDF 在工作区内随文章区域宽度适配。

## 已确认的会话流转规则

用户已确认：切换会话保留当前文章。文章与阅读位置属于工作区，不从会话恢复；选中会话只切换历史和该会话的草稿。点击文档或引用仍可主动切换文章。

## 尚待冻结的流转规则

当前三个视图切换仍带有导航标签等联动，以下只是下一轮建议，尚未执行：

1. 将“当前会话”“当前文章”“布局”分别管理；阅读／研读／对话只改变布局。
2. AI 入口在已打开问答时聚焦输入；纯阅读时有文章则进入研读，无文章则进入对话。
3. 打开文章／点击引用时保留当前会话，必要时进入研读；引用另外定位原文。
4. 侧栏开关只控制自身，不连带改变视图、文章或会话。窄屏以同一状态下的问答／文章单区呈现，并保留返回位置。

流转规则及引用执行链路继续讨论；本轮仅发布已确认的 UI 修改到 5175。


## 2026-09-25 输入区与来源菜单修复

- 输入区与发送按钮为同一容器：自动增高的文本域在上，模型、推理强度及圆形发送按钮共用底部一行；生成时原位切换停止按钮。空输入使用中性禁用状态。
- 文本域不绘制独立黑色聚焦框，外层容器保留柔和的焦点提示；Ctrl / Command + Enter 继续发送，输入法组字期间不触发提交。
- 标题栏统一为 48px，会话行约 44px，缩小消息、来源及输入区的内外间距。未打开文章时，空阅读器不会覆盖窄屏导航或对话。
- 来源默认显示三个紧凑行，以已保存的文档名与摘录呈现；右侧页码打开定位菜单，支持方向键、Escape 和焦点返回。菜单直接使用已有 sourceSpans 和 anchor，不新增请求、不推断未保存的逐页摘要。
- 保留旧的正文引用渲染和全部服务端执行逻辑。文本视图、章节映射、引用校验及 SSE 时机仍待讨论。
- 本地完整 CI：367 项测试通过，TypeScript 和构建通过；浏览器本地合成数据验证 27 项，包括五种宽度的对话／研读布局、来源展开与菜单、草稿保留、输入法保护、发送／停止及高度限制。浏览器验证不创建账号、不写测试数据库、不调用真实模型。
