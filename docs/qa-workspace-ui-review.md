# 工作区 UI 候选实现与流转讨论

2026-09-25。状态：代码已实现并完成本地检查；隔离预览运行在 5175 / 8791。用户要求先完成按钮修复、再讨论工作区流转，因此尚未替换 5174 / 8789 验收入口，未部署生产，未声称人工验收通过。

## 实现范围

- 顶部仅保留阅读／研读／对话切换、AI 问答、自由翻译、更多工具。文献库、服务状态、账号、选择模式和设置收纳在更多工具中，支持 Escape 和点击外部关闭。
- 左侧会话／文档导航与右侧注释区使用同一套 30 × 30 无边框按钮，图标 16px，同一水平位置；关闭后的展开按钮留在各自边缘。右侧仅显示注释。
- 会话侧栏支持服务端搜索、分页、置顶、内联重命名和软删除撤销；修改受服务端用户及 workspace scope 校验。单独删除过的回答不会因撤销会话删除而恢复。
- 每个已打开会话保留组件状态，视图／会话切换不取消后台回答；不同会话的草稿分开。刷新网页不承诺恢复未发送草稿。
- 工具事件附加 harness 生成的 `payload.activity`，包含实际文档名、页范围、章节、查询词、发现数量和未读完状态。此数据不加入模型上下文。旧历史缺少该字段时继续展示旧摘要，不推断虚构阅读位置。
- 来源默认显示 3 个，可展开／收起；保留正文引用和逐页定位，不再重复显示同一批来源快捷入口。
- 首轮等待为中性的“正在准备回答…”，发生工具事件后才展示具体查阅过程。PDF 在工作区内随文章区域宽度适配。

## 尚待冻结的流转规则

当前三个视图切换仍带有导航标签等联动，以下只是下一轮建议，尚未执行：

1. 将“当前会话”“当前文章”“布局”分别管理；阅读／研读／对话只改变布局。
2. 切换会话默认保留当前文章；也可按用户偏好恢复该会话上次文章，需确认。
3. AI 入口在已打开问答时聚焦输入；纯阅读时有文章则进入研读，无文章则进入对话。
4. 打开文章／点击引用时保留当前会话，必要时进入研读；引用另外定位原文。
5. 侧栏开关只控制自身，不连带改变视图、文章或会话。窄屏以同一状态下的问答／文章单区呈现，并保留返回位置。

部署继续安排在流转规则确认之后。
