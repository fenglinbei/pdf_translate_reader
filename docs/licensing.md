本许可适用于附带它的版本或副本。GitHub 仓库公开、支持 Fork，
以及 package.json 中的 `private: true`，均不是项目的商业使用许可。
`private: true` 是 npm 发布控制，不表示 GitHub 仓库私有。

在添加本许可前核查的 `main` 与 `qa-agent` 分支及其可见历史中，
未发现项目级 LICENSE 或 package.json 的许可字段。
这不是对仓库之外是否存在独立授权的认定。此前有效授予的独立许可
