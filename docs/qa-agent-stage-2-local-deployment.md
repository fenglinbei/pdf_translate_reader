引用保存为 `document_text`，定位到 `1 Method` 章节、第 1 页第 2 行。历史接口恢复相同 evidenceKey；数据库步骤序号连续，逐模型调用日志与唯一终态日志均存在。

数据库使用真实 authenticated 角色验证本人引用读写，以及跨用户读取/写入、过期解析版本和不完整定位的拒绝。服务端也拒绝另一个账号读取该文档。

Playwright 使用真实认证会话、实际前端与本地 QA API，核验历史恢复、章节标签、关键句整行高亮和无索引就绪提示。截图保存在本机 `output/playwright/qa-p2/`。本轮真实链路主要覆盖第 1 页关键句；跨页选择与缺坐标降级的浏览器验证来自此前合成 API 的组件测试，不能混为本轮真实数据库覆盖。

## 交给用户的验收

1. 刷新原来的 5174 测试页面，登录测试账号；问答模型默认应为 DeepSeek V4.1 Flash。
2. 打开一篇 MathPix 已完成的真实论文；无需建立 QA 索引。
3. 提问“XXX 在文中是怎么实现的”，核验回答中的章节引用和关键句所在行高亮，再刷新页面检查历史引用。
4. 继续检查跨页原文、中文提问英文论文、多轮追问、取消和文档中不存在答案的情况。

工程验证不能替代用户对真实论文的内容与引用支持程度验收，也未建立相对于旧 RAG 的质量、延迟或费用优势。逐字高亮、跨文档与图像理解不在本轮范围。
