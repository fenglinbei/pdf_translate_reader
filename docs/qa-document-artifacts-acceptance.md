## 待人工验收

1. 普通问题“你是什么模型”：可直接回答，首轮状态不强称检索。
2. “阅读这篇文章时，重点要读哪里”：工具过程显示阅读位置，正文词形正常，答案无需额外引用工具。
3. 输出尚未结束时点击引用；再从粗体/列表内点击，检查标签持续可用、页码与高亮合理。
4. 跨文档提问并点击来源；切换会话时当前文章保持不变。
5. 查看升级前的旧回答及引用，确认兼容；本轮新增回答刷新后仍可定位。

第一次使用已有解析文章可能需要生成一次版本化产物。后续重复提问应复用；未解析文章不会自动产生 OCR 费用。人工验收完成后再记录结果，本轮不宣布生产发布。
